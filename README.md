# Browser Tools

A small collection of browser-based utilities. No installation, no build step — just open the HTML files directly.

Created by [TwisterMc](https://www.twistermc.com/)

## Tools

### Gantt Editor (Beta)

`gantt-editor.html`

Plan and track projects with a zoomable timeline.

- Tasks and subtasks with start/end dates and progress tracking
- Zoom between day and week views
- Auto-saves to IndexedDB (your data stays in your browser)
- Export and import via `.gantt` files
- Resizable sidebar panel

### Sitemap Editor (Alpha)

`sitemap-editor.html`

Visually design site architecture with a node-based hierarchy editor.

- Drag-and-drop node layout
- Export site structure

## Usage

Open `index.html` in your browser to see all tools, or open any tool directly.

Data is saved locally in your browser via IndexedDB. Use each tool's export function to back up your work — there is no server-side storage.
